securityLab: 25 landing pages

Twenty-five versions of one landing page for a company that sells modular, pay-as-you-go security tools to developers, AI agents, and companies of any size. The process went wide, narrowed, converged, and then took one last wild swing that ended up winning. “securityLab” is a placeholder name; this is a design prototype, and every product, API, package, and price shown is a placeholder that does not exist.

Final choice · v25

The tool shelf

v25 introduces securityLab as a company with a product line, not a single API. The tiles are the actual tools (whereami in private beta, two planned, and a slot to suggest the next one), and the printed receipt turns the business model into line items: contract $0.00, minimum $0.00, lock-in none.

Every playful element carries real information, which is what separated the winners from the losers all along. It speaks to developers, agents, and larger teams on the same page, and it leaves obvious room for the next tools on the shelf.

The surprise: honestly, I didn’t expect this one to win. Rounds 3 and 4 had converged on a refined docs-style page (v22), and the last three versions were meant as experiments. The wild swing beat the safe pick.

How we got here

  1. Round 1 · Going widev01–v05

    Five themes: defense console, old newspaper, Nordic minimal, elegant split-screen, fire lookout. They looked like themed exercises, not companies: themes worn as costumes, no clear offer, no product, no trust.

  2. Round 2 · Real companiesv06–v10

    Defined the real audience and product, then aimed each version at a different visitor. The developer-first page (v07) and the agent-native page (v08) stood out.

  3. Round 3 · One style, five structuresv11–v15

    Combined v07’s look with v08’s content, sharpened the positioning (whereami detects residential proxies, nothing more), and varied only the structure. The docs-as-landing-page layout (v12) won.

  4. Round 4 · Convergingv16–v22

    One deliberate change per version: the red “Lab” wordmark, honest early-access calls to action, an inline try-it, dark mode (added, then reverted), polish, and an icon diagram of the attack.

  5. Round 5 · Going wildv23–v25

    Three big swings with the same product and story: a Unix man page, a scroll-driven 12-millisecond story, and a colorful tool shelf. The tool shelf became the final choice.

Round 2 · Real companies, different visitors

Round 1 looked like themed exercises, not companies: themes worn as costumes, no clear offer, no product, no trust signals. Round 2 starts from the actual product (whereami, login-time risk scoring, pay-as-you-go) and the bar “would this pass as a real production site?” Each version targets a different visitor.

Missionv06

Defense-tech tone (Palantir, Anduril): black, wide uppercase type, a quiet field of logins with a few turning red. Minimal text.
Developer-firstv07

Stripe/Resend structure: code in the hero with language tabs, integrations strip, how-it-works, signals grid, pricing calculator.
Agent-nativev08

For AI agents and vibe coders: a prompt to paste into your coding agent, a spec sheet, and a Human/Agent toggle that shows an llms.txt view.
Evidencev09

For technical evaluators: precision/recall chart, a live-looking stream of decisions, benchmark table, evaluation methodology.
Founder-ledv10

For small business owners: plain language, a letter on why it exists, enterprise vs. us comparison, pricing with real-world examples.

Round 3 · Narrowing: one style, five structures

v07’s visual style and v08’s agent-first content were the favorites, so round 3 combines them and holds the look constant. The positioning also got sharper: whereami detects residential proxy IPs and nothing more, which makes it a modular building block rather than an auth provider or a risk-score black box. The variable now is page structure.

Straight mergev11

v07’s layout carrying v08’s content: agent prompt, zero-to-key, spec sheet, and the Human/Agent toggle with an llms.txt view.
Docs as landing pagev12

Stripe-docs layout: sticky section sidebar, quickstart-style center column, and a code panel that follows the section you’re reading.
Narrativev13

One column read like a launch post: the correct-password attacker, a proxy diagram, one question and one field, your rules, small tools.
Playground firstv14

The hero is a working demo: pick or type an IP, see the response, a plain-English answer, and the matching cURL. Explanation comes after.
Audience splitv15

Leads with the company. A Developers / AI agents / Companies switch swaps the main panel, followed by a catalog of the tools.

Round 4 · Converging on v12

v12’s docs-as-landing-page structure won: it feels like the product is already in your hands, and the dark code panel shows the product instead of describing it. From here, each version makes one deliberate change.

Wordmarkv16

v12 with the “securityLab” wordmark carried over from v09: “Lab” set in the accent red.
Honest calls to actionv17

The product doesn’t exist yet, so “Get API key” became “Request early access”: a private-beta badge, planned pricing, and an early access section.
Try it inlinev18

Sample IPs in the Response section update the dark code panel with a request, a response, and a plain-English answer. Sample data only.
Dark modev19

Follows the system setting. Colors moved into tokens; the code panel stays dark in both modes.
Polishv20

Keyboard focus rings, skip link, smoother code-panel transitions, reduced-motion support, and a shorter call to action on phones.
Attack diagram, light onlyv21

Dark mode reverted: the page is designed to be seen as intended. Adds an icon-only left-to-right diagram of the attack: attacker → proxy network → hijacked home → your login.
Sharper diagramv22

A simpler head-and-shoulders attacker icon, and “hijacked home” becomes the more precise “hijacked device” on a real customer’s home connection.

Round 5 · Going wild

With v22 as a solid baseline, the last three versions take big swings in concept, color, and layout while keeping the same product, story, and placeholder rules.

The man pagev23

whereami is named like a Unix command, so the page is its manual: NAME, SYNOPSIS, EXIT STATUS, BUGS, in amber on warm charcoal, with a live $ whereami <ip> prompt.
12 millisecondsv24

A scroll-driven story following one login attempt in real time, with a running clock from stolen password to whereami’s answer to the MFA rule that stops it.
The tool shelf FINALv25

Leads with the company: periodic-table tool tiles on cream, an expandable whereami drawer, and a printed receipt where “contract” and “lock-in” are $0.00 line items.
